# Interface web

Une application, plusieurs pages : vue parc, vue bassin (avec vue 3D), historique, configuration
des seuils et console d'incidents. Elle passe par l'API du serveur de parc, sauf la console qui
appelle l'API du simulateur.

Langage : TypeScript / React. Voir le [périmètre](../docs/PERIMETRE-POC.md#62-interface-web).
